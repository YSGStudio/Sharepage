# 칸별 작성 규칙 상세

실제 언남초 수업 나눔 지도안 8편(사회4·수학6·통합2·과학4·국어4·국어5·창체5·영어3)에서 추출한 규칙이다.

## 목차
1. 1쪽 개요면
2. 2쪽 전개면
3. 분량 기준표

---

## 1. 1쪽 개요면

### 헤더 (검색창 형식)
- **학년/학기/교과**: "4학년 1학기 사회", "5학년 1학기 창의적 체험활동"
- **제목**: 8~15자. 학생 활동이 보이는 동사형이 좋다.
  - 좋음: `우리가 만드는 지역역사축제` / `자연 속 무늬로 옷 디자인하기` / `영어로 말하는 동물 카드 만들기`
  - 나쁨: `문화유산의 이해` (명사형 나열, 활동이 안 보임)
- **연관검색어**: 3~5개. 두 가지 표기 다 쓰인다.
  - 나열형: `비  비율  기준량  비교하는 양`
  - 해시태그형: `#지진피해 #대처방법 #장소별행동요령`

### 수업소개
3~4문장, 120~200자. 다음 순서로 쓴다.
1. 이 차시에서 학생이 하는 일
2. 사용하는 디지털 도구와 산출물
3. 이 수업의 주안점 (무엇을 기르려 하는가)

예: "동물 이름을 영어로 읽고 쓰는 활동을 한다. ChatterPix Kids 앱을 활용하여 자신이 찍은 동물 사진에 영어로 녹음한 목소리를 입혀 '말하는 동물 카드'를 만들고 친구들과 공유한다. 이 과정에서 동물을 나타내는 영어 단어의 소리와 철자 관계를 익히고, 영어 표현에 대한 흥미와 자신감을 기른다."

### 기본표
| 칸 | 작성 규칙 |
|---|---|
| 단원 | "2단원", "4단원" 또는 단원명("AI 리터러시", "자연") |
| 대상학급 | "4학년 2반" |
| 일시 | "2026.5.26.(화)" |
| 차시 | "12/12차시" + 아래 줄에 교과서 쪽수 "(86-88쪽)" |
| 수업모형 | 항상 **BRIDGE 프로젝트 모형** |
| 교과역량 | 2개. 해당 교과 교육과정 역량명 사용 |

교과역량 실제 사용례: 협력적소통역량·추론 역량(사회) / 추론·문제해결역량·의사소통역량(수학) / 창의적사고 역량·심미적 감성 역량(통합) / 과학적 탐구능력·과학적 문제해결력(과학) / 문화 향유 역량·비판적창의적 사고 역량(국어) / 공동체·대인관계 역량(창체) / 의사소통역량·추론 역량(영어)

### 교육과정 분석
- **성취기준**: `[4사06-01] 지역의 문화유산을 통해 …` 형식. 교과 통합 시 2~3개 병기. 핵심 어구는 굵게 처리해도 좋다.
- **3범주**: 각 10~25자의 구절. 문장이 아니라 명사구·동사구로 끊는다.
  - 지식·이해 → 개념·사실 (예: "비율의 개념", "갈래(시)", "동물을 나타내는 단어의 소리와 철자")
  - 과정·기능 → 하는 일 (예: "자료 분석하기", "감각적 표현 활용하여 표현하기")
  - 가치·태도 → 태도·정서 (예: "지혜로운 선택", "작품 감상의 즐거움", "쓰기 윤리 준수")
- **탐구질문**: 물음표로 끝나는 한 문장. 학습목표를 그대로 질문으로 바꾼 것이 아니라, 학생이 궁금해할 만한 실제 문제여야 한다.
  - 예: "포장 무게와 가격이 모두 다른 상품들 사이에서 가성비 높은 상품을 찾아내는 방법은?"
  - 예: "소화기관 중 하나가 제 기능을 못하게 된다면 몸 전체에 어떤 일이 일어날까?"

### 학습목표
1~2문장. 수행과제가 문장 안에 드러나야 한다.
- 1문장형: "자연 속 무늬로 옷을 꾸밀 수 있다."
- 2문장형: "문화유산에 대한 역사적 사실을 정리하여 발표자료를 만들 수 있다. / 제작한 발표자료를 자신감 있는 태도로 설명할 수 있다."

### 평가계획
- **평가요소**: 1~2개. 명사구. "비율 계산 및 분석하기", "지진피해 조사 및 대처 능력"
- **상/중/하**: 각 30~70자, 행동으로 서술.
  - 상 = 교사가 제시한 문장 그대로 다듬기
  - 중 = 핵심 조건은 갖췄으나 완성도·구체성·독립성이 부족 ("~할 수 있으나 도움이 필요함")
  - 하 = 시도했으나 핵심 조건 미달 ("~하기 어려워하며", "~일부 말할 수 있다")
- **피드백**: 주로 '하' 학생 지원 방안. 도구·자료 이름을 구체적으로 적는다.
- **평가방법 및 도구**: 2~3가지 조합. 예 `산출물평가(캔바, 투닝), 동료평가체크리스트(구글폼)` / `관찰평가(스마트기기 활용), 산출물 평가(Padlet), 자기성찰평가(구글 폼)`

### BRIDGE 단계별 수업 전략
3칸 각각 1~3문장, 40~90자. **활동 나열이 아니라 그 단계의 설계 의도**를 쓴다.
- BR: 무엇으로 문제를 인식시키는가 (자료 + 정서적 반응 + 탐구 질문 도출)
- ID: 어떤 방법·도구로 문제를 해결하는가
- GE: 무엇을 공유하고 어떻게 성찰하는가

### 디지털·AI 활용 목적 / 디지털 도구
- 단계별 칸에 배치. 해당 없는 단계는 **비워둔다**(실제 지도안에도 공란 있음).
- 목적 5종과 도구 목록은 `phrasebank.md` 참고.

### 학생 주도성 향상 전략
- 4요소 중 실제 장면이 있는 것만 체크. 미체크 사례 실재(수학 차시 '소통·협력' 미체크, 과학 차시 '도전·책임'·'자기성찰' 미체크).
- 서술 3~5문장. 각 문장이 한 요소에 대응하도록 쓰면 읽기 좋다.
- 문장 끝은 "~하도록 한다 / ~게 한다 / ~높인다" 형태.

## 2. 2쪽 전개면

### 열1: BRIDGE 단계
`BR / 문제·발견인식 / (7')` 처럼 약자 + 국문 + 시간. 시간 표기는 생략된 지도안도 있으나 넣는 것을 기본으로 한다.

### 열2: 교수·학습활동

**BR 고정 뼈대**
```
◉ 전시 학습 상기
◉ 동기 유발
◦ (동기유발 활동명)
  - (발문 1~3개)
◉ 학습 문제 확인하기
  【학습문제】 ~해 봅시다.
◉ 학습 활동 안내하기
  [활동1] … [활동2] … [활동3] …
```
동기 유발은 대부분 ①영상 ②퀴즈(띵커벨/멘티미터) ③실물·경험 떠올리기 중 하나다.

**ID 뼈대**
```
◉ 활동1 (활동명)
◦ 하위 활동
  - 발문 / 지시
◉ 활동2 (활동명)
◦ …
```
활동명은 학습 활동 안내에 적은 것과 **글자 하나까지 동일**해야 한다.

**GE 뼈대**
```
◉ (활동3 또는 공유·감상 활동)
◉ 자기 평가하기
  - 자기평가 문항 2~3개 (물음형)
◉ 정리하기 / 차시 예고하기
  - 다음 시간에는 ~해 보겠습니다.
```

### 열3: 자료 및 지도전략
- 태그 순서 관례: `[자료]` → `[유의점]` → `[피드백]` → `[평가]`
- 주도성 향상 박스는 해당 활동 옆에 배치. BR에 ①, ID에 ②③, GE에 ④가 오는 것이 가장 흔한 배치다(고정은 아님).
- 유의점이 여럿이면 ① ② ③ 번호를 붙인다.
- 한 칸에 3~5개 요소면 충분하다. 열2보다 분량이 많아지면 안 된다.
