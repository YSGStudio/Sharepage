# BRIDGE 프로젝트 모형 초등 교수·학습과정안 작성 스킬

## 목적

언남초등학교(AI디지털 연구학교) 수업 나눔 양식에 맞춘 **2쪽짜리 교수·학습과정안**을 작성한다.
교사가 그대로 한글 표에 옮겨 붙일 수 있는 수준의 문장·분량으로 출력해야 한다.

- **1쪽 개요면**: 수업의 설계 의도(무엇을·왜·어떻게 평가하는가)
- **2쪽 전개면**: 3열 표 — BRIDGE 단계 / 교수·학습활동 / 자료 및 지도전략

---

## BRIDGE 3단계 (반드시 이 정의를 쓴다)

| 단계 | 영문 | 국문 | 수업 위치 | 권장 시간(40분) |
|---|---|---|---|---|
| **BR** | **B**uzz · **R**ecognize | 문제 발견·인식 | 도입 | 5~8분 |
| **ID** | **I**nquire · **D**evelop | 해결방법 탐색·문제해결 | 전개 | 22~27분 |
| **GE** | **G**row · **E**nrich | 공유·성찰 | 정리 | 7~10분 |

절대 6단계(Buzz/Related/Investigate/Do&Make/Give&Share/Evaluate)로 쓰지 않는다.
활동은 보통 **활동1~3**으로 구성하며, 활동1~2는 ID, 활동3(또는 마무리)은 GE에 배치한다.
활동이 2개면 활동1·2를 ID에 두고 GE는 정리·자기평가·차시 예고로 채운다.

---

## 필수 입력 (교사가 직접 제시해야 하는 항목)

아래 중 하나라도 없으면 **작성을 시작하지 말고 한 번에 모아서 묻는다.** 이미 준 것은 다시 묻지 않는다.

| 항목 | 설명 |
|---|---|
| 학년·학기·교과 | 예: 4학년 1학기 사회 |
| 단원·차시·교과서 쪽수 | 예: 2단원 / 12차시 중 12차시 / 86-88쪽 |
| 성취기준 | 2022 개정 코드+문장. **Claude가 임의로 만들지 않는다.** 통합 수업이면 여러 개 |
| 학습목표(도달목표) | 이 차시가 끝나면 학생이 할 수 있어야 하는 것 |
| 수행과제 | 학생이 실제로 만들거나 해내야 하는 결과물·활동 |
| 평가기준 '상' 서술 | 가장 잘 수행한 학생의 모습 한두 문장. 여기서 평가요소를 추출하고 중·하를 도출한다 |

**선택 입력** (없으면 합리적으로 제안하되 "(제안)" 표시)
- 대상학급·일시, 교과역량 2개, 사용할 디지털 도구, 수업 시간(기본 40분)

**질문 예시**
> BRIDGE 교수·학습과정안을 쓰기 위해 아래를 알려주세요.
> ① 학년·학기·교과 ② 단원/차시/교과서 쪽수 ③ 성취기준(2022 개정 코드) ④ 학습목표 ⑤ 수행과제(학생 산출물) ⑥ 평가기준 '상' 서술
> 쓰실 디지털 도구가 정해져 있으면 함께 알려주세요.

## 출력 절차

1. 필수 입력 확인 → 부족하면 질문하고 중단
2. `references/format-spec.md`를 읽어 각 칸의 작성 규칙과 글자 수를 확인한다
3. 표현이 막히면 `references/phrasebank.md`(실제 지도안에서 뽑은 문장 패턴·도구 목록)를 참고한다
4. 아래 순서 그대로 **1쪽 → 2쪽** 출력
5. 마지막에 한 줄로 확인 요청: 바꾸고 싶은 활동·도구가 있는지

파일(.hwp/.docx/.pdf)은 사용자가 명시적으로 요청할 때만 만든다.

## 출력 형식

### ■ 1쪽 — 개요면

```
[학년 학기 교과]
제목: (검색어처럼 짧은 동사형 문구)
연관검색어: (핵심어 3~5개)

■ 수업소개
(3~4문장. 무엇을 하는 차시인지 + 어디에 주안점을 두었는지)

■ 교수·학습과정안
| 단원 | | 대상학급 | | 일시 | |
| 차시(교과서 쪽수) | | 수업모형 | BRIDGE 프로젝트 모형 | 교과역량 | (2개) |

■ 교육과정 분석
- 성취기준: [코드] 문장
- 지식·이해 / 과정·기능 / 가치·태도: (각 한 구절)
- 탐구질문: (물음표로 끝나는 한 문장)

■ 학습목표
(1~2문장, "~할 수 있다")

■ 평가계획
| 평가요소 | 상 | 중 | 하 | 피드백 |
| 평가방법 및 도구 | (예: 산출물평가(캔바), 동료평가 체크리스트(구글폼)) |

■ BRIDGE 단계별 수업 전략
| BR 문제 발견·인식 | ID 해결방법 탐색·문제해결 | GE 공유·성찰 |
| (2~3문장) | (2~3문장) | (2~3문장) |

■ 디지털·AI 활용 목적
| BR: | ID: | GE: |   ← 개별화/실시간피드백/협력학습/확장경험/창작 중 선택(없으면 공란)

■ 디지털 도구
| BR: | ID: | GE: |

■ 학생 주도성 향상 전략
☑ 선택·결정  ☑ 도전·책임  ☑ 소통·협력  ☑ 자기성찰   ← 해당 항목만 체크
(3~5문장. 어떤 장면에서 그 요소가 발현되는지 구체적으로)
```

### ■ 2쪽 — 전개면 (3열 표)

```
| BRIDGE 단계 | 교수·학습활동 | 자료 및 지도전략 |

BR
문제 발견·인식
(7')
    ◉ 전시 학습 상기
    ◉ 동기 유발 [아이콘]
    ◦ (활동명)
      - (학생에게 하는 청유형 발문)
    ◉ 학습 문제 확인하기
      【학습문제】 ~해 봅시다.
    ◉ 학습 활동 안내하기
      [활동1] / [활동2] / [활동3]
                                      → [자료] / [유의점] / 주도성 향상①

ID
해결방법 탐색·문제해결
(25')
    ◉ 활동1 (활동명) [아이콘]
    ◦ 하위 활동
      - 발문
    ◉ 활동2 …
                                      → [자료] / [유의점] / [피드백] / [평가] / 주도성 향상②③

GE
공유·성찰
(8')
    ◉ 활동3 또는 공유·감상
    ◉ 자기 평가하기
    ◉ 정리 및 차시 예고하기
                                      → [평가] / 주도성 향상④
```

**기호 체계 (고정)**
- `◉` 대활동 / `◦` 중활동 / `-` 세부 발문·지시
- 세부 발문은 학생을 향한 청유형: "~해 봅시다", "~인가요?"
- 학습문제·활동명은 박스로 표시

**자료 및 지도전략 4종 태그**
- `[자료]` 실물·PPT·앱 등 준비물 → 명사구로
- `[유의점]` 그 차시에만 해당하는 지도 주의점. 2개 이상이면 ①② 번호
- `[피드백]` 어려워하는 학생 지원 / 결과 환류 방식
- `[평가]` 무엇을 어떻게 볼 것인지 (평가계획과 연결)

**주도성 향상 번호(고정)**: ①선택·결정 ②도전·책임 ③소통·협력 ④자기성찰
→ 해당 단계 옆 칸에 제목 + 2~3줄 서술로 붙인다.

## 작성 원칙

**발문은 실제 교실 말투로.** "비교한다"가 아니라 "달걀 한 개의 가격을 구할 때 기준량이 되는 것은 무엇일까요?"처럼 그대로 읽어도 되는 문장으로 쓴다.

**디지털 도구는 목적과 함께.** "패들렛 활용"이 아니라 "패들렛 — 모둠별 조사 내용을 실시간 공유하고 댓글로 상호 피드백"처럼 쓴다. 도구 개수는 차시당 1~3개면 충분하다. 도구가 많을수록 좋은 수업이 아니다.

**주도성 4요소는 '체크'가 아니라 '장면'으로 증명한다.** ①선택·결정에 체크했으면 학생이 무엇을 골랐는지가 활동에 실제로 있어야 한다. 근거가 없으면 체크하지 않는다(실제 지도안에도 미체크 사례가 있다).

**평가는 '상' 서술에서 역산한다.** 교사가 준 '상' 문장에서 평가요소를 뽑고, 중=핵심 조건은 갖췄으나 완성도 부족, 하=시도했으나 핵심 조건 미달로 서술한다. "잘함/보통/미흡" 같은 라벨만 쓰지 않는다.

**학년별 톤을 다르게.**
- 1~2학년: 놀이·조작·감상 중심, 활동 2개, 발문 짧게
- 3~4학년: 협동·제작 중심, 활동 2~3개
- 5~6학년: 토의·탐구·산출물 중심, 활동 3개, 역할 분담 가능

**세 단계의 시간 합이 수업 시간과 맞아야 한다.** 40분이면 7+25+8처럼 명시한다.

## 하지 말아야 할 것

- BRIDGE를 6단계로 쓰기 → 반드시 BR/ID/GE 3단계
- 성취기준 코드를 지어내기 → 교사가 준 코드를 그대로. 없으면 요청
- 학습목표·수행과제·평가 '상'을 Claude가 대신 만들기
- "안전에 유의한다", "적극 참여하도록 한다" 같은 어느 수업에나 붙는 유의점
- 디지털 도구 이름만 나열, 또는 단계마다 다른 도구를 5개씩 넣기
- 주도성 4요소 전부 무조건 체크
- 요청 없이 파일 생성
- 1쪽만 쓰고 끝내기 → 개요면과 전개면은 항상 세트
